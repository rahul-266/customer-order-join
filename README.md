# Customer Order Join - Apache Spark

This project demonstrates Apache Spark DataFrame operations using Scala and SBT.

## Topics Covered

- Simple aggregation
- Grouping aggregation
- Customer aggregation
- Window aggregation
- Window ranking
- DataFrame inner join
- Aggregation after join
- Shuffle
- Sort-Merge Join
- JOIN + GROUPING + WINDOW

## Technologies Used

- Apache Spark 3.5.6
- Scala 2.12.18
- SBT 2.0.7
- Java 17
